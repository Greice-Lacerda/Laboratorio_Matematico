# 🧮 Laboratório Matemático: Primeiros Passos com Python

Bem-vindo ao meu repositório de autoria digital! Este projeto faz parte da minha jornada no ecossistema **Math Fusion Tech**, onde exploro como a programação pode ser uma ferramenta poderosa para o ensino e a prática da matemática.

## 🎯 Objetivo
O objetivo deste repositório é documentar a transição do pensamento matemático analógico para a automação computacional, utilizando a linguagem Python para resolver problemas cotidianos e pedagógicos.

## 📂 Scripts Desenvolvidos

### 1. `calculos.py`
Este script explora os **operadores matemáticos fundamentais**. Ele serve como base para entender como o computador processa:
* Soma, Subtração, Multiplicação e Divisão.
* Potenciação e Resto da divisão.

### 2. `media_escolar.py`
Um automatizador de **médias aritméticas**. 
* **Finalidade:** Calcular a média final de um aluno a partir de quatro notas bimestrais.
* **Conceito Aplicado:** Precedência de operadores e manipulação de variáveis decimais (float).
